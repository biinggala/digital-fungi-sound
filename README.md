## 1. 기본 단위: 퍼셉트론 대신 "균사 팁"

퍼셉트론은 입력을 받아 출력 하나를 내는 정적인 함수다:

$$y = \sigma(\mathbf{w}\cdot\mathbf{x} + b)$$

균사의 기본 단위는 함수가 아니라 **자라나는 끝(hyphal tip)** 이다. 상태는

$$s = (\mathbf{p},\ \theta,\ c) \quad \text{(위치, 진행 방향, 소속 군체)}$$

이고, 매 tick마다 아래 규칙을 수행한다. 팁이 지나간 자리는 세그먼트(노드)로 남아 네트워크가 된다.

| # | 규칙 | 식 |
|---|---|---|
| 1 | **감지** (화학굴성 + 음성 자기굴성) | $S(\mathbf{q}) = \chi\,N(\mathbf{q}) - \alpha\,\rho(\mathbf{q})$  — $N$: 토양 양분, $\rho$: 균사 밀도 |
| 2 | **조향** | $\theta \leftarrow \theta + \mathrm{clip}\big(k\,[S(\mathbf{p}+d\,\hat u_{\theta+\phi}) - S(\mathbf{p}+d\,\hat u_{\theta-\phi})],\ \pm\Delta\big) + \xi$ |
| 3 | **성장** | $\mathbf{p}' = \mathbf{p} + v\,\hat u_\theta$, 비용 $c_g$를 군체 저장고에서 지불 |
| 4 | **분기** (측면, 몇 마디 뒤에서) | $P_{\text{branch}} = \beta\,(0.3 + 2.5\,N(\mathbf{p}))$ — 양분이 많을수록 촘촘히 (탐색 ↔ 착취) |
| 5 | **융합** (anastomosis) | 같은 군체 균사와 $\lVert \mathbf{p}' - \mathbf{v} \rVert < \varepsilon$ 이면 간선을 이어 **고리**를 만들고 팁 종료. 다른 군체면 대치선에서 멈춤 |

## 2. 네트워크: 학습되는 것은 가중치가 아니라 "굵기"

각 세그먼트 $i$는 흡수량 $a_i = \kappa N(\mathbf{x}_i)$와 유지비 $m_i = m(0.5 + D_i)$를 가지고, 순소비량은 $b_i = m_i + c_g[\text{새 팁}] - a_i$ 이다.

### 수송: 네트워크 전체를 저항 회로로 푼다

수송은 성장보다 훨씬 빠르다고 보고(준정적 가정), 트리 간선 + 융합 간선 전체를 회로로 보고 키르히호프 방정식을 푼다.
간선 전도도 $g = D + \varepsilon$, 노드 "압력" $P$, 군체마다 뿌리(포자)를 $P = 0$으로 접지:

$$L(g)\,P = -b, \qquad Q_{ij} = g_{ij}\,(P_i - P_j)$$

그래서 **융합으로 생긴 고리가 실제 우회로가 된다.** 두 갈래가 이어지면 흐름이 나뉘고, 더 잘 흐르는 쪽이 굵어진다.
$Q > 0$ 이면 그 너머는 양분을 **받아 쓰는 쪽**(성장 중인 팁), $Q < 0$ 이면 **흡수해서 내보내는 쪽**(먹이에 뿌리내린 가지)이다.

### 적응: 쓰면 굵어지고, 안 쓰면 가늘어진다

$$D \leftarrow D + \lambda\left(f(|Q|) - D\right), \qquad f(q) = \frac{(q/Q_0)^\mu}{1 + (q/Q_0)^\mu}$$

경쟁 지수 $\mu$가 네트워크의 성격을 정한다 (Tero et al. 2010의 점균 모델과 같은 구조):

- $\mu \le 1$: 평행한 길들이 흐름을 나눠 가지며 공존 → 여러 갈래로 땋인 그물. 대신 양분이 줄면 전부 같이 가늘어진다.
- $\mu > 1$: 평행한 길끼리 경쟁 → 이긴 길이 굵은 줄기가 되고 진 길은 끊긴다. (기본값 1.5)

말단이면서 $D < \delta$ 인 세그먼트는 자가분해(autolysis)되어 양분 일부를 돌려준다. 아무것도 못 찾은 탐색 가지는 한 마디씩 후퇴하고, 먹이와 성장 전선을 잇는 길만 굵은 균사삭(cord)으로 남는다.

**고리 경쟁**: 융합 간선이 자기 고리 위의 가장 약한 트리 간선보다 1.5배 이상 굵어지면 둘의 역할을 바꾼다. 밀려난 약한 길은 융합 간선이 되어 가늘어지다 끊기고, 그 뒤로 말단부터 후퇴한다.

## 3. 전기 신호: 각 세그먼트가 흥분성 단위

실제 균사체에서도 전기 스파이크가 측정된다 (Adamatzky). 여기서는 각 세그먼트를 뉴런 막 모델의 단순화판인
**FitzHugh–Nagumo** 단위로 두고, 굵기만큼 이웃과 전기적으로 잇는다:

$$\frac{dv}{dt} = c\,v(v-\alpha)(1-v) - w + \sum_j k\,(g_0 + D_{ij})(v_j - v_i), \qquad \frac{dw}{dt} = \varepsilon(\gamma v - w)$$

$v$는 막전위(휴지 0, 흥분 ≈1), $w$는 회복 변수, $\alpha$는 문턱. 굵은 균사삭일수록 결합이 강해 신호가 빠르다 (케이블 이론).

- **언제 쏘나**: 팁이 아직 아무도 차지하지 않은 먹이에 처음 닿을 때, 가끔 저절로 (자발 발화), 사용자가 "전기 자극"으로 클릭할 때.
- **무엇을 하나**: 스파이크를 맞은 팁은 40 tick 동안 분기 확률이 $(1 + r)$배가 된다 — "어딘가 먹이가 있다 → 더 탐색". **가설적 규칙**이다 (실제 균류에서 확인된 메커니즘이 아님). 켜면 새 가지가 약 1.8배 늘었다 (시드 3개, 1500 tick 평균: 5,777 → 10,435).
- **화면**: 신호에 새 색을 얹지 않는다. 막 흥분한 균사가 자기 군체 빛깔로 밝아지며 살짝 굵어지고, 밝기는 흥분 × 신선함 $v\,(1 - w/0.25)$ 이라 앞쪽 띠가 가장 밝고 회복 변수 $w$가 쌓이는 뒤쪽은 옅어진다. 지나간 자리는 불응기 동안 잠깐 어두워졌다가 $w$가 빠지며 돌아온다.
- **관찰**: "전극 꽂기"로 세그먼트 하나를 고르면 패널의 오실로스코프에 $v(t)$가 그려진다. 지나가는 파동은 급상승 → 고원 → 급하강의 활동전위 모양이다.

### 수치 해법: Hines 방법

결합 항을 명시적으로 풀면 안정 조건 때문에 tick당 수십 번 계산해야 신호가 성장보다 빨라진다.
그래서 결합은 트리 위에서 **암묵적으로** 푼다: $(I - \Delta t\,k\,L_{\text{tree}})\,v' = \text{rhs}$ 는 잎 → 뿌리 소거, 뿌리 → 잎 대입으로 O(N)에 정확히 풀린다.
신경 시뮬레이터 NEURON이 가지 친 뉴런을 푸는 Hines(1984) 방법과 같다. 융합 간선은 자기 쪽만 암묵적으로(상대 쪽은 직전 값) 더해 항상 안정하다.
덕분에 결합을 $k = 200$까지 키울 수 있고, 신호 속도 $\propto \sqrt{k}$ 라서 굵은 줄기에서 성장보다 15배쯤 빠르다.

### 만들면서 발견한 현상

- **분기점 차단**: 표준 FHN 파라미터($\alpha \approx 0.7$, 약한 흥분성)에서는 같은 굵기 두 갈래로 나뉘는 분기점마다 파동이 죽었다 (한 가닥의 전류로 두 가닥을 흥분시키지 못함). 문턱을 $\alpha = 0.06$으로 낮춰 해결.
- **임계 핵**: 결합이 강하면 한 점만 자극해서는 이웃이 전류를 빨아가 불이 안 붙는다. 전기적 길이 $\lambda \propto \sqrt{k}$ 반경을 한꺼번에 흥분시켜야 한다. 특히 굵은 줄기 여러 개가 모이는 포자 자리는 모든 방향으로 반경을 잡아야 했다.
- **재진입 (reentry)**: 고리가 파장(속도 × 불응기)보다 길면 신호가 고리를 끝없이 돈다 — 심장 부정맥과 같은 현상이고, 신경망의 순환 연결이 지속 활동(기억)을 만드는 것과 같은 구조다.
  성장·자극을 멈춰도 $\varepsilon = 0.01$에서는 활동이 영원히 이어졌고, 트리(고리를 전기적으로 끊음)에서는 사라졌다.
  기본값 $\varepsilon = 0.003$ (불응기를 늘려 파장 > 고리)에서는 파동이 한 번 지나가고 꺼진다. 패널의 "회복 속도 ε"를 0.01 근처로 올리면 직접 볼 수 있다.

## 4. 신경망과 비교

|  | 퍼셉트론 / ANN | 디지털 균사 |
|---|---|---|
| 단위 | 뉴런: 가중합 → 활성화 | 팁: 감지 → 조향 → 성장 / 분기 / 융합 |
| 구조(위상) | 사람이 설계, 고정 | **스스로 자라남** — 구조 자체가 출력 |
| 학습되는 값 | 가중치 $w$ | 전도도 $D$ |
| 학습 규칙 | 역전파 (전역 기울기) | 국소 흐름 규칙만 (전역 정보 없음) |
| 흐르는 것 | 정보(활성값) | 물질(양분) + 전기 스파이크 |
| 목적함수 | 명시적 loss | 암묵적: 흡수 − 유지비 ("스스로 먹고 살기") |
| 계산 결과 | 입력 → 출력 | 네트워크 모양 자체 (먹이 사이 경로, 자원 배분) |

## 5. 코드 구조

- `src/mycelium.js` — 모델. DOM 없음, Node에서도 돌아감 (`require('./src/mycelium.js')`).
  - `solveFlow()`: 수만 개 노드의 회로를 통째로 풀지 않는다. 트리 간선 흐름은 $Q_i = T_i + X_i$ ($T$ = 서브트리 소비 합, $X$ = 서브트리에서 융합 간선으로 빠져나가는 양)이고, $X \ne 0$ 인 곳은 융합 간선 끝점들을 잇는 경로뿐이다.
    1. 융합 끝점과 그 경로들의 분기점만 남긴 **축약 그래프**를 만들고 (보통 수백~3천 개),
    2. 그 사이 사슬은 직렬 저항 $R = \sum 1/g$ 와 부하 항 $A = \sum T/g$ 로 접은 뒤,
    3. 최소 차수 순서 **희소 가우스 소거**로 정확히 풀고 (`eliminate()`),
    4. $X$를 사슬과 서브트리로 되돌려 모든 간선의 $Q$를 채운다.

    KCL·KVL 모두 정확히 만족한다 (검증: 조밀 가우스 소거와 상대오차 ~5e-8, 실제 네트워크에서 KVL ~1e-7).
    트리 전처리 켤레기울기법(PCG)도 시도했는데, 융합 간선이 수백 마디짜리 긴 고리를 만들어서 수렴에 150~230회가 필요해 버렸다.
  - `rebalanceLoops()` / `swapEdge()`: 고리 경쟁 (트리 간선 ↔ 융합 간선 교환, 경로의 부모 방향 뒤집기).
  - 회로는 `flowEvery` tick마다 다시 푼다 (D가 천천히 변하므로). 죽은 노드가 쌓이면 `compact()`가 배열을 압축.
  - `stepElectric()`: FHN + Hines 소거. `stimulate()`: 반경 λ 흥분. `setProbe()` / `trace`: 기록 전극.
  - `stepMat()`: 균사 매트 (Fisher–KPP, 부하를 회로 노드에). `stepFruits()` / `startFlush()`: 결실. `stepSpores()`: 포자 비행 · 휴면 · 싹틈. `massBalance()`: 질량 장부.
- `src/main.js` — 캔버스 렌더링(굵기 구간별 Path2D 배칭), 스파이크 표시, 오실로스코프, UI.
- `src/sound.js` — Web Audio 소리 (`MyceliumSound`). 모델을 읽기만 하고, 모델 쪽에는 `sim.events`(파동 시작 사건 목록) 하나만 더했다.
- `src/i18n.js` — 한/영 문구 (`t(키)`, HTML은 `data-i18n` 속성).
- `serve.py` — 캐시를 끈 개발 서버 (`python -m http.server`는 고친 스크립트 대신 캐시된 옛 파일을 내줄 수 있다).

## 7. 다음 실험 아이디어

- **고리의 쓸모 측정**: 고리 있는 네트워크와 트리만 있는 네트워크에 가지를 무작위로 끊는 손상을 주고, 어느 쪽이 양분 공급을 더 잘 유지하는지 비교 (실제 균사체에서 고리의 존재 이유로 꼽히는 내결함성).
- **신호로 계산하기**: 두 파동이 만나는 지점(동시성 검출), 재진입 고리를 기억 소자로 쓰기 — 자라난 네트워크가 실제로 입력 → 출력 함수를 계산하게 만들 수 있을까.
- **손상 신호**: 균사를 자르는 도구를 만들고, 상처에서 나온 스파이크가 나머지 네트워크의 행동(예: 상처 쪽으로 재성장)을 바꾸게.
- **균사 컴퓨터**: 도시 위치에 먹이를 놓고 네트워크가 최소 연결망(Steiner tree 근사)을 찾는지 보기, 미로 풀기.
- **진화**: 파라미터를 유전체로 두고, 군체끼리 경쟁시켜 GA로 진화.
- **3D**: 같은 규칙을 3차원으로 → Blender로 렌더링.

## 8. 소리

원칙: **노드 수만 개를 소리 수만 개로 만들지 않는다.** 프레임마다 네트워크를 한 번 훑어 숫자 몇 개(특징)로 모으고,
지속음은 그 숫자로 파라미터만 부드럽게 움직이며, 사건음은 동시 발음 상한(전체 32, 종류별 2~10) 안에서만 낸다.
**무엇을 듣는지**(아래 특징 · 사건)는 고정이고, **어떻게 들리는지**는 소리 요소(채널)마다 따로 고른다. 모든 음높이는 고른 음계 위에 있어서 무엇이 겹쳐도 어울린다.

### 믹서: 채널마다 스타일을 밀어서 섞기

믹서에는 소리 요소마다 한 줄씩 있다:
성장(팁) · 먹이 발견 · 파동 시작 · 스파이크 · 재진입 박동 · 기록 전극 · 드론(우웅) · 화음·파면 · 공간.

- **스타일 띠** (색 블록): 왼쪽부터 연구실 → Eno → Moss Garden → Green-House → Aphex → Sun Ra. 한 스타일 자리에 두면 그 스타일의 악기로,
  **두 스타일 사이에 두면 두 악기가 같은 사건에 함께** 울린다 (세기는 √무게로 나눠서 전체 크기는 같다). 놓을 때 스타일 근처(±0.08)면 딱 붙는다.
  이웃한 두 스타일끼리만 섞인다 (연구실과 Aphex를 섞으려면 둘을 다른 채널에 두면 된다). 순서는 섞었을 때 어울리는 것끼리 이웃하게 골랐다
  (Moss Garden은 Eno와 Bowie가 함께 만든 곡이라 Eno 옆, Sun Ra는 가장 거친 전자음인 Aphex 옆).
- **반응**: 채널마다 실제 소리를 분석기(AnalyserNode)로 엿들어, 그 크기(RMS, −60 ~ −8 dBFS)만큼 줄이 빛난다 — 손잡이 근처 블록이 밝아지며 솟고 채널 이름이 밝아진다 (바로 오르고 천천히 내려감). 격자에 맞춰 나중에 울리는 소리도 실제로 울릴 때 반응한다. 드론 · 화음 줄은 지속음을, 공간 줄은 잔향 · 에코 꼬리를 보여준다.
- **음량**: 0이면 그 채널을 끈다. 예를 들어 드론을 0으로 하면 계속 깔리던 '우웅'이 사라진다.
- **프리셋** 버튼: 모든 채널을 한 스타일로 보내고, 으뜸음 · 음계 · 잔향 · 에코도 그 스타일 값으로 바꾼다. 그다음 채널 하나씩 옮기며 섞는다.
- **박자**는 채널이 아니라 스타일을 따른다. Green-House로 연주되는 소리는 84 BPM 8분 격자에, Aphex로 연주되는 소리는 흐름 BPM 16분 격자에,
  Eno 쪽은 격자 없이 흐트려서 낸다. 시계가 스타일마다 따로 돌기 때문에 섞으면 **폴리리듬**이 된다 (패널에 `♩84 · ♩141`처럼 뜬다).
- 지속음 채널(드론, 화음·파면, 공간)은 두 스타일의 값을 선형으로 섞는다: 음량, 톱니파 비중, 밝기, 흔들림 깊이·빠르기, 짧은 방/긴 홀 비율,
  에코 길이(움직이면 테이프처럼 음이 미끄러진다), 깨끗한/비트 깎은 파면 잡음 비율.

예: 성장 = Green(칼림바 아르페지오), 먹이 발견 = Aphex(애시드 베이스), 재진입 박동 = Eno(숨), 드론 음량 0, 공간 = Eno.

### MIDI 출력

소리 줄의 **MIDI → 연결**을 누르고 출력 포트를 고르면, 균사체 사건이 MIDI 음으로 신스 · DAW에 나간다 (Chrome · Edge의 Web MIDI, GitHub Pages 사이트에서. 아티팩트 안에서는 안 된다).
macOS에서 DAW로 보내려면 '오디오 MIDI 설정 → MIDI 스튜디오 → IAC 드라이버 → 기기가 온라인 상태'를 켜고 그 포트를 고른다.

| MIDI 채널 | 믹서 채널 | 보내는 것 |
|---|---|---|
| 1 | 성장 | 성장음 하나마다 음 하나 |
| 2 | 먹이 발견 | 음 (화면 위쪽일수록 높게) |
| 3 | 파동 시작 | 음 (북 소리 스타일이면 36) |
| 4 | 스파이크 | 음 (스네어 스타일이면 38, 연타 포함) |
| 5 | 재진입 박동 | 음 (킥 스타일이면 36) |
| 6 | 기록 전극 | 음 |
| 7 | 드론 | 지금 드론 음을 계속 누름 (크기에 따라 바뀜) · CC74 = 양분 흐름 |
| 8 | 화음 · 파면 | 굵은 고리 수만큼 쌓인 화음을 계속 누름 · CC1 = 파면 크기 |
| 9 | 버섯 | 원기 아르페지오 · 포자 흩뿌림 · 싹틈 |

- 음높이는 지금 그 스타일 악기가 내는 음 그대로(음계 · 으뜸음 따름). 음높이가 없는 악기(킥 · 스네어 · 하이햇 · 잡음)는 채널마다 고정 음.
- 세기 = 소리 세기, 길이 = 악기 울림에 맞춰 (0.25 ~ 1.6초). 박자 격자에 맞춰 나중에 울리는 소리도 MIDI 타임스탬프로 같은 순간에 나간다.
- 믹서에서 음량 0인 채널은 MIDI도 안 나간다. **음소거해도 MIDI는 나간다** (브라우저 소리는 끄고 외부 악기만 쓰기). 소리 켜기는 필요하다.
- 슬렌드로처럼 반음이 아닌 음계는 가장 가까운 반음으로 반올림된다.
- 포트를 '끔'으로 바꾸거나 연결이 끊기면 모든 채널에 All Notes Off를 보낸다.

같은 음이 좌우로 엇갈려 돌아오며 매번 다른 조합을 만든다. 여기에 균사체의 사건 자체가 불규칙하게 들어오므로 같은 반복이 없다.

아래 표들은 연구실 스타일 기준이다. 다른 스타일은 같은 특징을 받아 위 표의 악기로 바꿔 낸다 (드론 · 화음 · 파면의 매핑은 공통이고, 스타일은 세기 · 음색만 바꾼다).

'우웅' 하고 계속 깔리는 소리가 **드론**이다: 네트워크 크기를 음높이로(클수록 낮게), 양분 흐름을 음량·밝기로 듣는 소리라서 균사체가 있는 한 항상 울린다.
그 위에 굵은 고리 수만큼 쌓이는 **화음**이 있다. 둘 다 믹서에서 음량을 낮추거나 끌 수 있다.

### 지속음: 네트워크의 모양

| 균사체 | 소리 | 매핑 |
|---|---|---|
| 세그먼트 수 (크기) | **드론 음높이** | 300개에서 으뜸음(D3), 두 배가 될 때마다 음계 한 칸 아래로 (D3 → C3 → A2 → … → A1). 클수록 깊다. 경계에서 떨지 않게 히스테리시스 |
| 굵은 균사삭 비율 (D > 0.65) | **드론 음색** | 0 ~ 20% → 톱니파 비중 ↑, 저역 필터 공명 ↑. 가는 그물은 둥근 사인, 굵은 줄기가 많으면 거칠고 쏘는 소리 |
| 전체 양분 흐름 Σ\|Q\| | **드론 음량 · 밝기** | log 스케일 (Σ\|Q\| 1 → 0.1, 30 → 0.55, 500 → 1). 많이 흐를수록 크고 필터가 열린다. 화음의 밝기도 같이 |
| 굵은 고리 수 (fD > 0.35) | **화음 두께** | 1, 3, 7, 15, 31, 63개 → 1~6성. 드론 위 음계 칸으로 옥타브, 옥타브+5도, 2옥타브, 그 위 두 칸, 2옥타브+5도 순으로 쌓인다 |
| 성장 중인 팁 수 | **바스락 (알갱이 밀도)** | 팁 수 → 초당 알갱이 (최대 60/s). 알갱이 하나 = 무작위 팁 위치(좌우)에서 나는 8~28ms짜리 띠 잡음. 일시정지하면 멈춘다 |
| 파면 크기 (V > 0.5 이면서 회복 변수 W < 0.1인 세그먼트 수) | **쉬익 + 웅** | 파면이 클수록 띠 잡음이 커지고 밝아지며, 드론 2옥타브 위 사인이 붙는다. 파면의 무게중심 x → 좌우 위치 |

### 사건음: 무슨 일이 일어난 순간

| 사건 | 소리 |
|---|---|
| 파동 시작 (`stimulate()` → `sim.events`) | 아래로 떨어지는 **'쿵'** (200 → 46 Hz). 클릭한 자극은 크게, 자발 발화는 작게, 실제로 불붙은 세그먼트 수만큼 크게. 자극 위치 → 좌우 |
| 새 먹이 발견 (`foodSignals` 증가) | **FM 종** (변조비 1.4 → 금속성, 2.4초 울림). 화면 위쪽일수록 높은 음. 발견이 쏟아지는 성장기에는 작게 반짝이고(최근 횟수에 반비례, 최소 0.15초 간격), 드문 발견은 크게 울린다 |
| 기록 전극을 지나가는 스파이크 | 짧은 **퉁김** (D5 톱니파 + 닫히는 필터). 오실로스코프의 0.5 상향 교차와 1:1 |
| 숨은 전극을 지나가는 스파이크 | 나무 **'톡'** (위치 y → 음높이). 아래 참고 |
| 먹이 주기 (클릭) | 물방울 **'퐁'** |

### 재진입 → 심장 박동

굵은 줄기(D > 0.35) 위 무작위 지점 16곳에 **숨은 전극**을 꽂아 두고 (죽을 때까지 같은 자리, `compact()` 뒤엔 새로 뽑음),
스파이크가 지나갈 때마다 '톡'을 낸다. 한 지점이 **짧고 일정한 주기**(최근 4간격 평균 < 400 tick, 변동계수 < 0.3)로 계속 울리면 재진입으로 보고,
그중 가장 규칙적인 두 곳이 울릴 때 저음 **'쿵-쿵'** (두 번째는 0.13초 늦게)을 붙인다. 패널에 `재진입 박동 ♥ n곳`이 뜬다.

처음엔 "자극보다 더 자주 울리면 재진입"으로 판정하려 했는데, 성장기에는 새 먹이 발견이 초당 수 번씩 자극을 넣어서 이 기준이 무너졌다.
고리 접합부(융합 간선 끝)에 귀를 대는 것도 실패했다 — 고리 경쟁 때문에 굵은 고리는 수백 개에서 몇 초 만에 한 자리 수로 줄고, 듣는 자리가 계속 바뀌어 기록이 쌓이지 않았다.
측정해 보니 재진입이 있으면 **고리 하나가 박동기(pacemaker)가 되어 네트워크 전체를 같은 주기로 때린다**:
ε = 0.01에서 무작위 줄기 지점 16곳 중 9곳이 105~185 tick 간격으로 함께 울렸고, ε = 0.003에서는 0곳 (간격 250~570으로 들쭉날쭉).
그래서 고리를 찾을 필요 없이 아무 줄기에나 귀를 대면 된다.

들어 보는 법: 포자 하나를 900 tick쯤 키운 뒤 (굵은 고리가 많을 때) "회복 속도 ε"를 0.01로 올리고 가운데를 자극한다.
ε = 0.003이면 '톡' 무더기가 몇 초에 한 번 쏟아지고 조용해지고, 0.01이면 파면의 쉬익이 끊기지 않고 1~2초 주기의 박동이 깔린다.
(이 모델은 고리 경쟁으로 고리가 금방 줄어서, 재진입도 고리가 남아 있는 동안만 이어진다.)

### 비용

`sound.update()`는 프레임당 평균 0.2 ms (p95 0.4 ms, 노드 3만 개; 가장 바쁜 Aphex 스타일, 노드 4.7만 개에서도 평균 0.13 ms).
주의: 모델의 배열은 `compact()` 전까지 죽은 칸이 쌓여 살아있는 노드의 몇 배(예: 18만 칸에 2.3만 개)가 된다. 처음엔 배열 전체를 훑어서 이때 1 ms까지 늘었는데,
지금은 모델의 트리 순회 순서(`sim.order`, 살아있는 노드만)를 훑는다 (2.8만 개에서 약 0.5 ms). `compact()` 직후 순서가 낡았을 때만 전체를 훑는다. 노드 배열을 훑는 일은 매 프레임 한 번(파면),
크기·굵기·흐름·고리는 15프레임에 한 번. 속도 6에서 소리를 1초씩 번갈아 켜고 끄며 잰 프레임률은 85.0 vs 84.7 fps로 차이가 없었다.
(연속 구간으로 재면 네트워크 자체가 계속 변해서 ±30 fps씩 흔들리니 꼭 번갈아 재야 한다.) 음소거 중에는 사건음을 아예 만들지 않는다.

## 9. 균사 매트와 버섯 (결실)

실제 균사체는 땅을 솜처럼 빽빽하게 채운 다음 버섯을 올린다. 화면을 꽉 채우려면 균사 수십만 가닥이 필요해서 하나하나 계산할 수 없다.
그래서 **이산 + 연속 혼합 모델**로 간다 (Boswell · Davidson 등의 균사체 모델과 같은 방식): 성장 전선과 줄기는 지금처럼 균사 하나하나, 그 사이를 메우는 가는 균사는 토양 격자(5 px 칸) 위의 **매트 밀도** $m \in [0, 1]$.

### 시간 · 공간 척도 (실측에 맞춘 보정)

모델은 원래 단위가 없다 (tick, px). 그래서 "빠르다 / 느리다"를 따지려면 척도부터 정해야 한다.

- **공간**: 1 px = 0.26 mm로 정한다 → 화면 가로 914 px ≈ 24 cm (균사삭 연구에서 흔히 쓰는 토양 미세계 크기). 이건 선택이다.
- **시간**: 모델의 균사 전선이 나아가는 속도를 쟀다 — 전체 노드 중 바깥 5%의 반지름을 시간에 대해 직선 맞춤, 무작위 토양 5판 평균 **0.73 px/tick** (0.41 ~ 0.88). 이것을 실측 **8.4 mm/일** (*Phanerochaete velutina*, 비멸균 토양, Bretherton et al. 2006)에 맞추면 0.73 × 0.26 mm = 0.19 mm/tick → **1 tick ≈ 33분**.
- 상태 줄에 시뮬레이션 날짜와 배속(실제 1초 ≈ 며칠, 120 Hz 화면 · 속도 1에서 ≈ 2.7일)이, 무대 오른쪽 아래에 축척 막대가 뜬다. 화면에서 순식간에 채워지는 것은 **저속 촬영**이라서다.

이 척도로 모델과 실측을 비교했다 (모델: 무작위 토양 12판):

| | 모델 | 실측 (대략) |
|---|---|---|
| 균사 전선 | 8.4 mm/일 (보정 기준) | 느타리 한천배지 7 ~ 15 mm/일 [1, 2], *P. velutina* 토양 8.4 mm/일 [3] |
| 땅을 90% 채움 | **15.5 ~ 21일** | 배양 기질을 다 덮는 데(spawn run) 대개 2 ~ 3주, 기질에 따라 8 ~ 38일 [4, 5] |
| 첫 결실 (원기 생김) | **24 ~ 30일** | 느타리 첫 수확 접종 후 24 ~ 33일 [4, 5] |
| 원기 → 성숙 | **5일** | 며칠 ~ 1주 [6] |
| 다음 결실까지 | 20 ~ 23일 | 재배에서 약 10일 [6] — **모델이 2배쯤 느리다** |

처음 보정했을 때는 땅 채우기는 맞았지만 **버섯이 16.5일 걸려 실측보다 3배 느렸다** → 버섯 싱크 세기를 0.01 → 0.033으로 (원기 → 성숙 220 tick ≈ 5일). 결실 사이 쉬는 기간 · 원기가 말라 죽는 기간 · 포자 방출 기간도 같은 척도로 날짜에 맞췄다.

[1] [Strain-specific features of *P. ostreatus* growth in vitro, BMC Biotechnol. 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10851480/) · [2] [ICAR Mushroom Research](https://epubs.icar.org.in/index.php/MR/article/download/133332/53519/496600) · [3] [Bretherton et al. 2006 (Cardiff ORCA)](https://orca.cardiff.ac.uk/id/eprint/62636/) · [4] [Nepal substrate trial](https://banglajol.info/index.php/RALF/article/view/59530) · [5] [SAU repository](https://archive.saulibrary.edu.bd/handle/123456789/4825) · [6] [UC ANR extension](https://ucanr.edu/sites/sfp/files/144812.pdf). 실측값은 균주 · 기질 · 온도에 따라 크게 다르다. 모델은 특정 종이 아니라 "전형적인 부후균"의 규모를 맞춘 것이다.

### 매트: Fisher–KPP

$$\frac{\partial m}{\partial t} = \nabla\cdot\big(D_m(P)\,\nabla m\big) + \Big[r\,m(1-m) + s\,\chi\,(1-m)\Big]\frac{N}{N+K} - \lambda\,m$$

| 항 | 뜻 | 값 |
|---|---|---|
| $D_m(P) = D\,\frac{P}{P+P_{1/2}}$ | 옆 칸으로 번짐. 군체 저장 양분 $P$에 달렸다 — 균사 끝의 신장은 내부 양분에 기댄다 | $D = 0.12$ 칸²/tick, $P_{1/2} = 5$ |
| $r\,m(1-m)$ | 로지스틱 자람 (Fisher–KPP) | $r = 0.02$ |
| $s\,\chi(1-m)$ | 명시적 균사가 지나간 칸($\chi = 1$)에서 매트가 생긴다 | $s = 0.05$ |
| $\frac{N}{N+K}$ | 토양 양분 $N$에 따른 제한 (Monod) | $K = 0.02$ |
| $\lambda$ | 자가분해: 적자면 $\lambda_{max}\cdot\frac{\text{적자}}{\text{유지비}}$, 파산하면 $\lambda_{max}$, 결실 중이면 $+0.0003$ | $\lambda_{max} = 0.002$ |

- 매트를 만들려면 양분이 든다 ($m$ 1당 0.05). 매트는 칸의 토양 양분을 흡수하고(0.002·m·N), 유지비를 낸다(0.00002·m, 호흡).
- **투자 한도**: 한 tick에 매트 자람에 쓸 수 있는 양은 $\alpha\,(P - P_{비축})$, $\alpha = 0.01$/tick, $P_{비축} = 3$. 원하는 양이 더 많으면 모든 칸을 같은 비율로 줄인다 (지난 tick의 총수요로 비율을 정해 칸 순서 편향이 없다). 나머지 수입은 저장으로 쌓인다 — 이게 없으면 수입을 전부 넓히는 데 써서 버섯 낼 저장 양분이 남지 않는 판이 있었다.
- **이 흐름들은 회로를 지난다**: 칸마다 매트의 부하(자람 비용 + 유지비 − 흡수 − 회수)를 그 칸의 명시적 노드에 붙인다(없으면 번져 온 칸에서 물려받은 노드, 그것도 없으면 뿌리). 그래서 키르히호프 풀이가 매트까지 포함해 그대로 정확하고, 매트가 먹는 곳 · 쓰는 곳 사이로 줄기가 굵어진다.
- 다른 군체가 차지한 칸으로는 번지지 않는다 (영 플럭스 경계). 확산은 지난 tick의 칸 주인으로 막고 열어서 쌍마다 대칭이다 → $\sum m$이 확산으로는 바뀌지 않는다.
- **수치 안정성**: 명시적 오일러 5점 스텐실. $4D + r + s \le 1$이면 $m$이 0 아래로도 1 위로도 가지 않는다 (최대 원리). 그래서 $D \le 0.2$, $r \le 0.06$으로 자른다.
- **우선순위**: 적자일 때는 가는 매트가 먼저 분해되고, 그 양분이 줄기를 지킨다 — 실제로도 굶는 균사체는 가는 균사부터 사라지고 균사삭이 남는다.

### 결실 (버섯)

| 단계 | 규칙 | 근거 |
|---|---|---|
| **언제** | 50 tick마다 판정. 매트가 120칸 이상, 저장 양분 5 이상이고, **최근 300 tick(≈ 7일) 매트 면적 증가율 < 3%(다 채움) 또는 순수입(흡수 − 유지비, ≈ 100 tick 평균)이 최고치의 25% 아래(기질이 바닥나기 시작)** | 재배에서 버섯은 기질을 다 덮은 뒤, 영양이 제한될 때 유도된다. **판정 기준 자체는 가설.** 빛 · 온도 · CO₂ 같은 환경 신호는 모델에 없다 |
| **어디** | 매트가 짙고(m > 0.5) 굵은 줄기(그 칸의 D 합)가 모이는 칸, 서로 50 px(≈ 1.3 cm) 이상. 예산 40마다 하나, 1 ~ 3개 | 원기는 균사가 뭉친 매듭(hyphal knot)에서 생긴다. 점수식은 **가정** |
| **얼마나** | 저장 양분의 50%(결실 투자)를 이번 결실의 예산으로 | 버섯 크기가 군체가 모은 양분에 비례 |
| **자람** | 버섯마다 싱크 세기 $0.033\cdot(B + 0.02B^*)(1 - B/B^*)$ → 원기에서 성숙까지 ≈ 5일. 같은 군체끼리는 저장고 · 예산 안에서 세기대로 나눔 → 큰 것이 더 받는다. 150 tick(≈ 3.4일) 동안 자라지 못하면 말라 죽음(abortion) | 싱크 세기 ∝ 크기는 **가정**. 원기 일부가 죽는 것은 실제 현상 |
| **양분 흐름** | 버섯 노드에 수요가 걸리므로 회로가 흐름을 그쪽으로 모은다 → **버섯을 향해 굵은 줄기가 생긴다.** 결실 동안 매트는 영양 생장을 멈추고 천천히 분해되어(0.0003/tick) 그 양분도 버섯 쪽으로 흐른다 | 결실 때 영양 균사의 양분 재배치 |
| **포자** | 97%까지 자라면 바이오매스의 30%를 포자 10개로 200 tick(≈ 4.6일)에 걸쳐 날린다. 비행 거리는 평균 90 px(≈ 2.3 cm)의 지수 분포(바람 없는 근거리 산포라는 **가정**). 내려앉아 휴면하다가, 그 칸에 매트가 없고 토양 양분이 0.01 이상이면 25 tick마다 50% 확률로 싹터 **새 군체**가 된다. 4000 tick(≈ 92일) 안에 못 싹트면 분해 | 포자는 감수분열로 생긴 새 개체 → 부모 군체와도 대치한다. 자기 균사체 안에서는 자리 잡지 못한다 |
| **끝** | 포자를 다 날린 버섯은 분해되어(0.4%/tick) 40%가 주변 토양으로 돌아가고 나머지는 분해자의 호흡. 결실이 끝나면 440 tick(≈ 10일) 쉰다 | |

**화면에는 버섯도 포자도 그리지 않는다.** 위에서 본 버섯 그림은 인위적이었고, 포자는 수 µm라 이 척도(1 px ≈ 0.26 mm)에서 보일 수 없다.
버섯이 생긴 곳은 양분이 그쪽으로 몰리며 **굵어지는 줄기**로 드러난다. 상태 줄에 버섯 수(지금/누적)가 뜨고, 믹서의 '버섯' 채널이 소리로 알려준다 (원기 = 오르는 아르페지오, 포자 = 높은 음이 흩어짐, 싹틈 = 한 음).
매트는 군체 빛깔의 옅은 솜으로 그린다. 조절 바 '결실' 줄: 매트 r · 매트 D · 포화 문턱 · 결실 투자 · 매트 보기.

### 검증

`massBalance()`가 **질량 장부**를 맞춘다: 양분은 토양 · 저장고 · 명시적 균사 · 매트 · 버섯 · 포자 사이를 옮겨 다닐 뿐이고, 들어오는 것은 먹이 · 사용자 포자 · 처음 토양 · 토양 재생, 나가는 것은 호흡과 화면 밖으로 날아간 포자뿐이다.
float32인 토양 격자는 "실제로 바뀐 만큼"을 장부에 적고, 매트는 64비트로 둬서 반올림까지 맞춘다.

헤드리스(914 × 713, Node)로 잰 값:

| 점검 | 결과 |
|---|---|
| 질량 장부 상대 오차 (매 tick) | 최대 **약 2 × 10⁻¹¹** |
| 키르히호프 전류 법칙 잔차 (매트 · 버섯 부하 포함, 500 tick마다 모든 노드) | 최대 **1 × 10⁻⁷** (상대) — 원래 풀이와 같은 수준 |
| 매트 밀도 범위 | 항상 0 ≤ m < 1 |
| tick당 계산 시간 | 2.4 ~ 4.6 ms (매트 갱신 약 0.9 ms) |
| 무작위 토양 12판 | **12판 모두** 채움(15.5 ~ 21일) → 첫 결실(24 ~ 30일) → 성숙(29 ~ 35일), 뒤이어 2 ~ 3번 더 결실 |

만들면서 고친 것 (모두 위 수치로 원인을 찾고 확인):
- 결실 판정을 "면적이 안 늘면"으로만 했더니 저장 양분이 가장 많은 때를 지나쳐 파산한 뒤에 판정이 와서 버섯이 안 생기는 판이 있었다 → "기질이 바닥나기 시작함"(순수입이 최고치의 25% 아래)을 신호로 추가.
- 매트 유지비를 올리자 매트가 수입보다 빨리 넓어져 결실 전에 파산했다 → 퍼짐을 저장 양분에 걸었다 ($D_m(P)$).
- 수입을 전부 매트 넓히기에 쓰는 판(저장 양분이 비축선 3에 붙어 있음)에서는 버섯을 못 냈다 → 투자 한도 $\alpha(P - P_{비축})$로 저장이 쌓이게 했다. 이것으로 12판 중 12판이 결실.
- 결실 뒤 줄기는 다 죽고 매트만 남는, 실제와 거꾸로인 결과 → 적자에 비례한 매트 분해로, 가는 균사가 먼저 사라지고 줄기가 남는다.
- **포자가 거의 싹트지 않는 것은 버그가 아니다**: 휴면 포자를 조사해 보니 전부 자기 군체의 매트(m > 0.05) 위에 있었다. 한 군체가 화면 전체를 덮으면 새 세대가 설 자리가 없다. 다른 군체와의 대치선 너머나 매트가 물러난 빈 땅이 있을 때 새 군체가 생긴다.

모델에 없는 것: 환경 신호(빛 · 온도 · 습도 · CO₂), 버섯의 수직 구조(대 · 갓 · 주름의 발생), 버섯의 빠른 팽창을 이끄는 물 흡수, 짝짓기(단핵 → 이핵 균사), 분해자 생태계.
